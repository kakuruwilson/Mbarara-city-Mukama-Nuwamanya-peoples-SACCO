Mobile Money Instructions for Members

Airtel Money: Dial *185# → Send Money → Enter SACCO Till Number → Enter Member Number as Reference → Enter Amount → Confirm with PIN

MTN Mobile Money: Dial *165# → Send Money → Enter SACCO Till Number → Enter Member Number as Reference → Enter Amount → Confirm with PIN

Members must include their Member Number (e.g., MCMNP-0001) in the reference field. Admin will receive notification and verify the deposit.
